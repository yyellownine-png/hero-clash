# HERO CLASH v2
Яркий игровой прототип Telegram Mini App.

Добавлено:
- карта из 5 миров;
- уровни и прогресс;
- экран боя;
- боссы;
- победа и лут;
- энергия и монеты;
- коллекция героев;
- награды;
- магазин;
- мобильная навигация.

Пока без сервера и без Termux. Следующий этап — Telegram WebApp API + backend/БД.
